## Overview

CopySVGTranslation raises specific exceptions to help diagnose issues during SVG translation workflows. The two primary exception types are:

* **`SvgStructureException`**: Raised when SVG structure validation fails during preparation
* **`SvgNestedTspanException`**: A specialized exception for nested `<tspan>` element issues
* **Standard Python Exceptions**: `FileNotFoundError`, `json.JSONDecodeError`, and XML parsing errors

## SvgStructureException Error Codes

The `SvgStructureException` class uses error codes to identify specific structural issues. Each exception instance has a `code` attribute (string identifier) and an `extra` attribute (additional context).

### 2. structure-error-css-too-complex

**Exception Type:** `SvgStructureException`

**When Raised:** During `make_translation_ready()` when the SVG contains a `<style>` element with CSS rules.

**Example SVG:**

```

```

**Error Message Format:**

```
structure-error-css-too-complex: [""]
```

**Cause:** The injection system needs to generate unique IDs and may conflict with CSS selectors. Complex CSS makes ID manipulation unpredictable.

**Resolution:**

1. Remove the `<style>` element from the SVG
2. Convert CSS rules to inline `style` attributes on individual elements
3. Use external CSS if the SVG is embedded in HTML

**Sources:** [tests/inject/test_inject2.py L89](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/tests/inject/test_inject2.py#L89-L89)

### 3. structure-error-invalid-node-id

**Exception Type:** `SvgStructureException`

**When Raised:** During `make_translation_ready()` when an element has an ID containing invalid characters (e.g., pipe `|`).

**Example SVG:**

```

```

**Error Message Format:**

```
structure-error-invalid-node-id: ["x|"]
```

The `extra` attribute contains a list with the invalid ID string.

**Cause:** SVG ID attributes must follow XML naming rules. The system uses IDs to generate unique identifiers for translated elements, and special characters can cause parsing issues.

**Valid ID Characters:** `[A-Za-z0-9_-]`

**Resolution:**

1. Rename the element's ID attribute to use only alphanumeric characters, hyphens, and underscores
2. Example: Change `id="text|123"` to `id="text-123"`

**Sources:** [tests/inject/test_inject2.py L90](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/tests/inject/test_inject2.py#L90-L90)

### 4. structure-error-text-contains-dollar

**Exception Type:** `SvgStructureException`

**When Raised:** During `make_translation_ready()` when text content contains a dollar sign (`$`).

**Example SVG:**

```

```

**Error Message Format:**

```
structure-error-text-contains-dollar: ["Foo $3 bar"]
```

The `extra` attribute contains a list with the full text content.

**Cause:** Dollar signs may conflict with internal text processing or template systems. This validation prevents potential issues with string interpolation.

**Resolution:**

1. Replace `$` with the word "dollar" or currency code
2. Use HTML entity `&#36;` if the SVG will be processed further
3. Use Unicode character alternatives

**Sources:** [tests/inject/test_inject2.py L91-L92](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/tests/inject/test_inject2.py#L91-L92)

### 5. structure-error-multiple-text-same-lang

**Exception Type:** `SvgStructureException`

**When Raised:** During `make_translation_ready()` when a `<switch>` element contains multiple `<text>` elements with the same `systemLanguage` attribute.

**Example SVG:**

```

```

**Error Message Format:**

```
structure-error-multiple-text-same-lang: ['la']
```

The `extra` attribute contains a list of duplicate language codes.

**Cause:** SVG `<switch>` elements should contain at most one child per language. Multiple children with the same language violate this constraint and make language selection ambiguous.

**Resolution:**

1. Consolidate multiple text elements into one
2. If they represent different text strings, split into separate `<switch>` blocks
3. Remove duplicate translations

**Sources:** [tests/inject/test_inject2.py L71-L81](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/tests/inject/test_inject2.py#L71-L81)

## XML Parsing Errors

### lxml.etree.XMLSyntaxError

**When Raised:** When parsing an SVG file with invalid XML structure.

**Common Scenarios:**

1. **Unclosed tags:** ``` ```
2. **Invalid namespace declarations:** ``` ```
3. **Special characters not escaped:** ``` ```

**Error Message Example:**

```
lxml.etree.XMLSyntaxError: Opening and ending tag mismatch: text line 1 and svg, line 1, column 20
```

**Resolution:**

1. Validate SVG using an XML validator
2. Ensure all tags are properly closed
3. Escape special characters: * `&` → `&amp;` * `<` → `&lt;` * `>` → `&gt;` * `"` → `&quot;` * `'` → `&apos;`
4. Use a proper SVG editor to generate valid XML

## Quick Reference: Error to Solution

| Symptom | Likely Cause | Solution |
| --- | --- | --- |
| `FileNotFoundError` | Missing SVG or JSON file | Check file path and existence |
| `XMLSyntaxError` | Invalid XML in SVG | Validate XML structure, check for unclosed tags |
| `structure-error-nested-tspans-not-supported` | Nested `<tspan>` elements | Use `fix_nested_file()` |
| `structure-error-css-too-complex` | `<style>` element present | Remove CSS or convert to inline styles |
| `structure-error-invalid-node-id` | Special characters in ID | Rename ID to alphanumeric with hyphens/underscores |
| `structure-error-text-contains-dollar` | `$` character in text | Remove or replace dollar signs |
| `structure-error-multiple-text-same-lang` | Duplicate language in `<switch>` | Consolidate or separate duplicate entries |
| Empty dict from `load_all_mappings()` | Invalid JSON in mapping file | Validate JSON syntax |
| No translations inserted | Text mismatch | Check text normalization, try `case_insensitive=True` |
