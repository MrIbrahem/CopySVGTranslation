This page documents the custom exception types defined in `CopySVGTranslation`, their hierarchy, and the specific structural errors they represent. These exceptions are primarily used during the validation and preparation phases to ensure an SVG is suitable for translation injection.

## Overview

The package uses a structured exception system where all custom errors inherit from a single base class. This allows developers to catch all package-specific errors or target specific structural issues.

| Exception Class | Purpose |
| --- | --- |
| `CopySVGTranslationError` | Base class for all errors in the package. |
| `SvgStructureError` | Raised when an SVG's XML structure is unsuitable for translation. |
| `SvgNestedTspanError` | Specific error for nested `<tspan>` or `<a>` elements within `<text>`. |
| `SvgParseError` | Raised when XML parsing fails. |
| `SvgIOError` | Raised for filesystem-related failures (missing files, write permissions). |
| `MappingError` | Raised when translation JSON mappings are invalid or missing. |

## SvgStructureError

`SvgStructureError` and its subclasses are raised when the SVG contains elements or attributes that the translation engine cannot safely process. These are typically caught during the `ValidateStructure` step of the preparation pipeline.

### Exception Attributes

Every `CopySVGTranslationError` (and thus every `SvgStructureError`) contains:

* **`code`**: A string identifier for the error (e.g., `structure-error-contains-tref`). [CopySVGTranslation/exceptions.py L38](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/exceptions.py#L38-L38)
* **`element`**: The `lxml` element object that triggered the error, if applicable. [CopySVGTranslation/exceptions.py L39](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/exceptions.py#L39-L39)
* **`extra`**: Any additional context, such as the problematic ID or text content. [CopySVGTranslation/exceptions.py L40](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/exceptions.py#L40-L40)
* **`label`**: A human-readable description retrieved from the internal i18n data. [CopySVGTranslation/exceptions.py L41](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/exceptions.py#L41-L41)

## SvgNestedTspanError

This is a specialized subclass of `SvgStructureError`. It is raised when the `NestedTspanFlattener` is configured with the `strategy="raise"` and encounters a `<tspan>` or `<a>` tag nested inside another `<tspan>`.
