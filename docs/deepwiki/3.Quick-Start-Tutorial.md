This page provides a practical, hands-on tutorial for using `CopySVGTranslation` to extract translations from a source SVG file and apply them to a target SVG file. It demonstrates the modern `SVGTranslationService` facade and the underlying data structures.

**Purpose and Scope**: This tutorial walks through the primary entry point for extracting and injecting SVG translations. For detailed API documentation, see [API Reference](/MrIbrahem/CopySVGTranslation/6.1-public-api-overview). For advanced features like title translations with year suffixes, see [Advanced Features](/MrIbrahem/CopySVGTranslation/5.1-title-translations-with-year-suffixes).

---

## Overview: What You'll Learn

This tutorial covers the primary translation workflow using the `SVGTranslationService`:

1. **Service Configuration**: Setting up the `TranslationConfig`.
2. **Extraction**: Collecting translation pairs from a multilingual SVG.
3. **Injection**: Applying those pairs to a new SVG target.
4. **Combined Workflow**: Performing both steps in a single call.

## Prerequisites

Before starting, ensure you have:

* Python 3.10 or higher installed [README.md L26](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/README.md?plain=1#L26-L26)

* Two SVG files: * **Source SVG**: Contains `<switch>` elements with `systemLanguage` attributes [README.md L6-L8](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/README.md?plain=1#L6-L8) * **Target SVG**: The document that needs translations applied.

## Data Flow and Objects

The system relies on specific data structures to pass information between extraction and injection phases.

### TranslationMapping Structure

This object holds the dictionary of translations found in the SVG.

| Field | Type | Description |
| --- | --- | --- |
| `new` | `dict[str, dict[str, str]]` | Source text → {Lang Code → Translation} |
| `tspans_by_id` | `dict[str, str]` | ID-based mapping for specific text elements |
| `title_new` | `dict[str, Any]` | Mappings for titles with year suffixes |
