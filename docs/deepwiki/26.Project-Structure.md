## Injection Module

The `injection/` submodule handles applying translations to SVG files, preparing SVG structure, and batch processing. This is the most complex submodule with four separate files.

### Directory Contents

| File | Primary Functions | Purpose |
| --- | --- | --- |
| `__init__.py` | Exports all injection functions | Public API surface |
| `injector.py` | `inject()`, `work_on_switches()`, `generate_unique_id()`, `load_all_mappings()` | Core injection logic |
| `preparation.py` | `make_translation_ready()`, `normalize_lang()`, `reorder_texts()` | SVG structure validation and normalization |
| `batch.py` | `start_injects()` | Batch processing multiple files |
| `utils.py` | `file_langs()`, `get_target_path()`, exception classes | Helper utilities and exceptions |

### Key Components

**`inject()` Function** [injection/injector.py L227-L332](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/injector.py#L227-L332)

The main injection entry point that:

* Validates input file existence [injection/injector.py L246-L249](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/injector.py#L246-L249)
* Loads translation mappings from JSON or receives them as parameters [injection/injector.py L251-L261](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/injector.py#L251-L261)
* Calls `make_translation_ready()` to normalize SVG structure [injection/injector.py L267](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/injector.py#L267-L267)
* Delegates to `work_on_switches()` for actual translation insertion [injection/injector.py L289-L295](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/injector.py#L289-L295)
* Tracks language changes using `file_langs()` [injection/injector.py L287-L322](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/injector.py#L287-L322)
* Returns statistics when `return_stats=True` [injection/injector.py L329-L330](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/injector.py#L329-L330)

**`work_on_switches()` Function** [injection/injector.py L67-L199](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/injector.py#L67-L199)

Processes each `<switch>` element to insert or update translations:

* Identifies default text nodes without `systemLanguage` [injection/injector.py L102-L110](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/injector.py#L102-L110)
* Determines available translations from mappings [injection/injector.py L119-L129](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/injector.py#L119-L129)
* Creates new `<text>` elements for each language [injection/injector.py L162-L194](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/injector.py#L162-L194)
* Updates existing translations when `overwrite=True` [injection/injector.py L144-L160](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/injector.py#L144-L160)
* Generates unique IDs using `generate_unique_id()` [injection/injector.py L166](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/injector.py#L166-L166)

**`make_translation_ready()` Function** [injection/preparation.py L72-L346](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/preparation.py#L72-L346)

Prepares SVG files for translation by:

* Validating SVG structure and checking for unsupported elements [injection/preparation.py L92-L130](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/preparation.py#L92-L130)
* Wrapping raw text nodes into `<tspan>` elements [injection/preparation.py L173-L193](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/preparation.py#L173-L193)
* Creating `<switch>` elements around text that needs translation [injection/preparation.py L258-L268](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/preparation.py#L258-L268)
* Assigning unique IDs to all translatable nodes [injection/preparation.py L242-L245](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/preparation.py#L242-L245)
* Splitting comma-separated `systemLanguage` values [injection/preparation.py L282-L337](https://github.com/MrIbrahem/CopySVGTranslation/blob/307ef348/injection/preparation.py#L282-L337)

## Code Organization Principles

The codebase follows these organizational principles:

1. **Separation of Concerns**: Extraction, injection, and utilities are in separate modules
2. **Layered Architecture**: High-level workflows (`workflows.py`) build on lower-level primitives (`extract()`, `inject()`)
3. **Public API Facade**: `__init__.py` files control what's exposed to external users
4. **Dependency Injection**: Functions accept file paths or pre-loaded mappings, enabling flexible workflows
5. **Error Handling**: Custom exception classes provide structured error information
