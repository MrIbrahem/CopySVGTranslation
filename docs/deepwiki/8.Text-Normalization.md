## Purpose and Scope

This document describes the text normalization system used by CopySVGTranslation to ensure reliable matching between source text and translations. Text normalization is a critical preprocessing step that handles whitespace variations, case differences, and other text inconsistencies that could prevent successful translation matching.

For information about the overall translation workflow, see [3.1 SVG Translation Workflow](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/3.1 SVG Translation Workflow)

 For details on the translation data format, see [3.2 Translation Data Format](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/3.2 Translation Data Format)

## Overview

Text normalization is the process of converting text into a standardized, canonical form. In CopySVGTranslation, this ensures that text extracted from SVG files can be reliably matched against translation keys, even when the text contains inconsistent whitespace, different casing, or other formatting variations.

The system provides the `normalize_text()` function as the primary normalization interface, which is used throughout the extraction and injection workflows. Additionally, the system handles language tag normalization via `normalize_lang()`.

### Core Functionality

The function performs the following transformations:

1. **Null handling**: Returns an empty string if input is `None`. [CopySVGTranslation/utils/text.py L50-L51](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/utils/text.py#L50-L51)
2. **Whitespace collapsing**: Splits the string by any whitespace and rejoins with a single space, effectively trimming leading/trailing space and collapsing internal multiple spaces. [CopySVGTranslation/utils/text.py L53](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/utils/text.py#L53-L53)
3. **Optional case normalization**: Converts the entire string to lowercase if `case_insensitive` is set to `True`. [CopySVGTranslation/utils/text.py L54-L55](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/utils/text.py#L54-L55)

## Language Normalization

The system also normalizes language tags (e.g., `systemLanguage` attributes) to a standard IETF-like form using `normalize_lang()`. [CopySVGTranslation/utils/text.py L11-L27](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/utils/text.py#L11-L27)

### Normalization logic:

* Splits tags by underscores, hyphens, or spaces. [CopySVGTranslation/utils/text.py L22](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/utils/text.py#L22-L22)
* Lowercases the primary language code. [CopySVGTranslation/utils/text.py L23](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/utils/text.py#L23-L23)
* Uppercases 2-letter subtags (e.g., `US`, `BR`) and titles other subtags. [CopySVGTranslation/utils/text.py L25](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/utils/text.py#L25-L25)

**Examples:**

* `'en_us'` -> `'en-US'`
* `'pt-br'` -> `'pt-BR'`

## Summary Table: Normalization Operations

| Operation | Implementation | `case_insensitive=True` Effect |
| --- | --- | --- |
| Leading/trailing whitespace | `text.strip()` via `split()` | Same |
| Multiple spaces | `split()` and `" ".join()` | Same |
| Tab/Newline characters | Handled by `split()` | Same |
| Latin uppercase | `normalized.lower()` | Converted to lowercase |
| Non-Latin scripts | `normalized.lower()` | Preserved (no case) |
| `None` input | Returns `""` | Returns `""` |
