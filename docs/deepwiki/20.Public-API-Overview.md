## Exported Entities Summary

The package exports core service classes, configuration objects, and data structures through the top-level `CopySVGTranslation` module.

| Category | Entity | Purpose |
| --- | --- | --- |
| **Primary Service** | `SVGTranslationService` | The main facade for extracting and injecting translations. |
| **Configuration** | `TranslationConfig` | Object used to customize matching strategies and workflow behavior. |
| **Data Structures** | `TranslationMapping`, `TranslationEntry` | Classes representing the internal state of translation data. |
| **Nested Handling** | `NestedStructureService`, `NestedTspanDetector`, `NestedTspanFlattener` | Utilities for identifying and repairing invalid SVG nesting. |
| **Results** | `RepairResult` | Data class representing the outcome of a nested structure repair. |
| **Exceptions** | `CopySVGTranslationError` | Base exception class for all package-specific errors. |

## Nested Structure Handling

The package provides specific tools to handle "Nested Tspans," which are `<tspan>` elements inside other `<tspan>` elements—a structure that often breaks translation injection.

### NestedStructureService

A high-level service to detect and repair nested elements.

**Location:** [CopySVGTranslation/nested/service.py](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/nested/service.py)

 (Exported in [CopySVGTranslation/__init__.py L14](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/__init__.py#L14-L14)

)

**Key Components:**

* `NestedTspanDetector`: Identifies if an SVG contains invalid nesting. [CopySVGTranslation/__init__.py L15](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/__init__.py#L15-L15)
* `NestedTspanFlattener`: Logic to flatten nested tags into a single level while preserving text. [CopySVGTranslation/__init__.py L16](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/__init__.py#L16-L16)
* `RepairResult`: Contains the status of the repair and the modified SVG tree. [CopySVGTranslation/__init__.py L17](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/CopySVGTranslation/__init__.py#L17-L17)

## Error Handling

All public API operations return or raise types derived from `CopySVGTranslationError`.

* **Result Objects:** High-level service methods like `extract` and `inject` return result objects containing a `success` boolean and an `error` message string. [tests/e2e/test_public_api.py L77-L78](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/tests/e2e/test_public_api.py#L77-L78)
* **Exceptions:** For fatal structural errors during SVG preparation, specific exceptions like `SvgStructureException` (documented in [Exceptions](/MrIbrahem/CopySVGTranslation/6.5-exceptions)) are used.
