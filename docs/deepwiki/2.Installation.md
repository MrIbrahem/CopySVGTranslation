## Dependencies

### Runtime Dependencies

CopySVGTranslation has one core runtime dependency:

| Package | Minimum Version | Purpose |
| --- | --- | --- |
| `lxml` | 4.9 | XML parsing and manipulation of SVG files |

The `lxml` library is essential for parsing SVG documents and managing `<switch>` elements and `systemLanguage` attributes.

**Sources:** [pyproject.toml L13](https://github.com/MrIbrahem/CopySVGTranslation/blob/d984a401/pyproject.toml#L13-L13)
